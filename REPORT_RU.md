## Что случилось по ходу

- Синхронный REST-вызов Pixen обрывался прокси на ~30 с: один ответ потерян при списании; картинка восстановлена из галереи бесплатно. Дальше — асинхронный MCP `create_image_pixen` с job_id.
- Промпт v1 со списком «Do not add wings, horns…» добавлял именно эти детали. Для неотправленных слотов — v2 без запретов (все паки), для пака 09 — v3 и v4 (слова «Sky Pirates»/«airship» превращали предметы в корабли, дирижабли и острова с фоном).
- Бесплатные пиксельные правки: стёрты крылья у часов (08_001), кристаллы-рожки куклы стали бантами (08_121), псевдобуквы на этикетке (08_014), нарисованный пейзаж за предметом (09_011, 09_022, 09_032); несколько иконок сдвинуты к центру; alpha везде 0/255.
- Иконки, где модель нарисовала близкий, но другой предмет, оставлены с исправленным названием (`name_en`), плановое имя — в `planned_name_en`. Пак 08: 21, пак 09: 28, пак 10: 15.
- Почти-дубли и «существа» вместо предметов заменены новыми генерациями (пак 09: 12, пак 10: 15).

## Проверки

Все 600 PNG 64×64, один кадр; экспорты 128/256 попиксельно равны увеличению; регионы атласов совпадают с исходниками; точных дублей видимых пикселей нет ни внутри паков, ни между ними; ZIP распаковываются, галереи открываются с 200 картинками. Детали по каждой иконке — `qa/qa_report.json` в папке пака. Сверка дублей с паками 01–07 не делалась: их файлов здесь нет.

Мягкие отметки (не брак): поле < 4 px у 15/17/24 иконок паков 08/09/10, >48 цветов у части иконок; 08_094 касается края листом плюща (не обрезан); 08_200 — перо, похожее по силуэту на 08_019 и 08_095.
