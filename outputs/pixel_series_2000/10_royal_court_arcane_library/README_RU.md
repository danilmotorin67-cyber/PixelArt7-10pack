# Royal Court & Arcane Library — Королевский двор и зачарованная библиотека

200 самостоятельных статичных пиксельных иконок. Исходник 64×64 PNG с прозрачностью, точные экспорты 128×128 и 256×256 (nearest neighbour), атласы, манифест и локальная галерея. Создано с помощью генеративного AI PixelLab (модель Pixen), каждая иконка проверена отдельно.

Назначение: Дворцовые квесты, архивы, академия, инвентарь учёного, дипломатия и книжные головоломки.

| Категория | Иконок |
|---|---:|
| Королевские регалии | 20 |
| Письменные принадлежности | 20 |
| Книги и кодексы | 20 |
| Архивное хранение | 20 |
| Приборы познания | 20 |
| Дворцовая посуда и церемонии | 20 |
| Принадлежности придворной академии | 20 |
| Печати и документы | 20 |
| Дворцовые коллекции | 20 |
| Зачарованная библиотека и её тайны | 20 |

Папки: `png_64/`, `png_128/`, `png_256/` — иконки; `atlases/` — общий атлас 1024×1024 (14 колонок, ячейка 68 px, сдвиг 2 px) и атласы категорий 5×4; `previews/` — обложка и контактные листы; `sample_20/` — по 2 иконки каждой категории из этих же 200; `preview.html` — галерея без интернета.
